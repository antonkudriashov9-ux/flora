# Цветочный мир · flora

Сайт цветочного магазина в Грязях: 40 товаров, поиск, категории, избранное, корзина и демонстрационное оформление. Next.js 16, React 19, TypeScript. Фотографии и каталог включены в проект.

## Запуск

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000.

## Проверки

```sh
npm run build
npm run lint
node --experimental-strip-types --test tests/flower-cart.test.ts
```

## Демо-режим

Заказы не отправляются, оплата и ВК не подключены. Корзина и избранное сохраняются в localStorage. Контактные данные формы не отправляются и не сохраняются.

## Обновление каталога

`scripts/import-flowers.mjs` принимает путь к исходному архиву магазина. Для запуска сайта исходный архив не требуется.
